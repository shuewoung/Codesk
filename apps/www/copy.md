# Codesk 对外文案

口号：进了 ICU，还要遥控 Codex
主卖点：无缝流转
一句话：电脑上的 Codex，手机上接着干。同一份 session，不停、不丢、不另开云。

## 能说

- 同一份 session，桌面、VS Code、手机来回切
- 电脑干活，手机接管
- 不是云端 Codex，是你自己那台电脑
- 一人一机，凭据不离家
- 扫码配对，出门接着干
- 和桌面 Codex 一模一样，不另起炉灶
- 官方 Remote 连接慢、不稳定；Codesk 更快更稳
- Happy / Paseo / MindFS 接不上电脑上正在跑的会话，只能新开

## 三点

1. 无缝流转：和桌面 / VS Code 看同一份对话。发、停、审批，出门接着干。
2. 一人一机：300 人就是 300 台 Hub。不搬账号，不共享 Codex。
3. 出门接着干：扫码连回自己的电脑。电脑休眠就停工。

## 对比口径

官方 ChatGPT Remote：能控电脑，但官方通道慢、容易断。Codesk 同样遥控你自己的机器，更快更稳。
Happy Coder：要用 `happy` 包装 CLI，切到手机时会重启会话，不是桌面那一份。
Paseo：远程新开会话，接不上电脑里已经在跑的 Codex。
MindFS：同样另起炉灶。电脑聊到一半，手机看不到那条线。

## 不说

- 不说端到端加密
- 不说 P2P
- 不说云端 Codex / 多人共用一个账号
- 不说离线队列
- 不说中继地址
