# 1. Web 前端

## 是什么

手机 / 平板 / 桌面浏览器里的 Codesk PWA。只负责界面和调用协议，不碰 `~/.codex`，不spawn 进程。

## 连谁

| 场景 | 页面来源 | 数据面 |
|---|---|---|
| 同一 WiFi | Hub `:18990` | `ws://` / 以后 `wss://` 同源 Hub |
| 出门 | VPS 静态站点 | `wss://<中继>` ，信封里带 `hubId` |
| 原生壳（以后） | 同一套页面 | 同一套协议 |

入口 URL 只在一处拼接（现有 `connectWS()`）。不要写死 `localhost`。

## 窗口 1 负责

- 登录拆两块：家里码 + 电脑地址；出门码 / 扫右边二维码。不要一个框两用
- 扫码配对（`?pair=` + `hk=` + `lan=`）/ 主机离线态
- 电脑上的「出门扫码」弹层只出中继一次性码，文案须写明不是家里码
- 中继模式下握手并加解密 `fwd.enc`（[06-e2e.md](06-e2e.md)）
- 会话列表、时间线、审批按钮、设置
- PLAN 里的纯前端：Diff 卡、命令卡、`acceptForSession`、`/` 菜单、子智能体展示、文件下载按钮
- PWA 清单、离线壳不要抢回（保持网络直取）

## 不准做

- 不要改 `server/` 或新建 `apps/relay`
- 不要第二套消息名
- 不要在前端解析 rollout / 调 `codex-ipc`
- 不要为 APK 加原生桥（第 4 项再做）

## 验收

- 断线重连、70s 看门狗仍在
- 未登录看不到会话
- Hub 离线有明确文案，不是无限转圈
- 局域网与中继两种入口能切，业务消息形状不变
