# 跨端工作台实施与验收

## 范围与安全边界

本轮在已有未提交工作上增量实施，不重写 Expo 前端、不恢复归档 PWA、不提交或推送、不重启真实 Hub。功能范围来自“可靠接续、工作台界面、跨端高级能力”三批需求。

- 正常路径优先控制同一 Desktop 执行现场，Hub 独立执行为既有备用路径。
- 不以删除写入锁实现交接。当前离线协议证据仅确认 `thread/unsubscribe` 存在，不证明其释放 writer；交接必须保守地检查运行时与全部在途写动作。
- 不确定的发送结果不能自动重放。服务端接收/路由成功不是模型任务已经完成。
- 草稿采用版本比较，冲突必须显式处理，不静默覆盖另一设备内容。
- Git 审阅只读；本轮不自动提交、回滚、切换分支。
- 浏览器验收使用本地隔离夹具和独立 Web 导出，不覆盖当前 `apps/mobile/dist-web`，不调用真实模型、不访问真实用户文件。

首轮正常 GUI 验证了登录、项目切换、草稿显式保存、排队取消、问题导航和 390×844 Web 布局，同时发现 Git 差异、补充输入、提示与文案问题。修复并冻结源码后已重新导出第二轮构建。

第二轮在隔离服务重启后的登录恢复阶段受阻：页面重连中，随后正常“重新配对”点击、DOM 观察和截图均超时。没有注入或强制操作绕过，未把最终 Git/输入/交接路径计为 GUI 通过。无法仅凭这些现象判定是页面无响应还是浏览器控制通道故障。

GUI 结束后另补明确认证失效处理：unauthorized/revoked 或 4401/4403 按 transport 失效凭据并持久停止重连，重新认证成功才恢复；1006 仍退避，不误删 Hub 身份、草稿和待确认日志。新增 9 项 Provider 回归通过，最终 `web-final/` 含该补丁，但未再做 GUI，不把补丁当成原超时根因的证明。

## 已明确的能力限制

- 命令 `succeeded` 仅表示发送被执行端接收或路由成功，不表示模型任务完成。
- 安全交接是全局空闲释放请求。`releaseRequested: true` 与 `writerReleaseConfirmed: false` 分开表示，不声称 Desktop 已获得写入权。其他任务、未决 RPC、审批、用户输入或未知运行状态会阻塞释放。
- 当前 Desktop IPC 的补充输入回答协议未获确认，明确不支持，不将其伪装成审批。IPC steer 的去重由 Hub 持久记录提供，未杜撰下游稳定消息 ID 字段。
- 草稿同步是显式保存/读取，并用版本比较解决冲突；不是未经确认自动覆盖桌面输入框。迁移旧连接命名空间时保留源备份，已有目标不覆盖；未提供单独的旧备份冲突选择页。
- 当前没有真机或模拟器运行证据。Android SDK/Java 可用，但无 emulator/AVD/ADB 设备。最终核对 AGP 8.11.0 字节码后，用进程级 UTF-8 与 `-Pandroid.overridePathCheck=true` 成功越过路径检查；加 `-Pandroid.builder.sdkDownload=false` 禁止自动下载，随后因缺 Build Tools 36.0.0（本机仅 35.0.0）失败，未生成 APK。未安装 SDK 或接受许可证。Windows 未执行 iOS 构建。
- 没有在用户真实 Codex Desktop 上发送任务来验证双向接续，不把协议/模拟运行时测试当成真实执行端验收。
- 中继下载需要升级后的 Relay 注入认证设备身份。老 Relay 缺身份时安全拒绝原件下载。
- 旧版匿名欢迎包及无公钥链接的兼容握手仍存在；本轮没有证明能抵御主动恶意 Relay 的全部公钥替换或重放攻击，不应做此安全承诺。
- 登录限流在单进程内按实际连接地址计数；重启清空，多实例不共享，反向代理后的用户可能共享额度。
- 工作台持久存储有明确上限：10,000 命令、2,000 队列条目、2,000 草稿、32 MiB 快照。到限后拒绝新写入，不静默删除去重记录；维护应停机备份后显式迁移，未提供在线清空按钮。
