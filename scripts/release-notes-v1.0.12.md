## 手机端

- 跨端工作台：顶部显示执行位置（本机 / Hub），空闲可交接、忙碌自动排队且可取消
- 会话接续更可靠：稳定请求 ID 与幂等去重，断线重连、回前台自动补齐历史，失败发送明确标出、不自动重放
- 草稿跨设备同步：同会话草稿按版本比较，冲突时显式提示，不静默覆盖另一设备内容
- 补充输入卡片：Hub 发起的提问在手机上作答，跨端同步关闭状态
- 只读 Git 审阅：变更文件列表 + 统一差异视图；不暂存、不提交、不回滚
- 原件下载：分块传输 + SHA-256 校验，失败可重试
- 键盘自适应优化：Android / iOS / Web 输入区避让更稳
- 「本次产物」面板视觉重构：分段标签与筛选胶囊、说明收进信息卡片、产物改为卡片式列表、空状态居中引导；轮次 ID 缩短显示并支持点按复制
